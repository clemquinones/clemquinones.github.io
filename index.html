About

Backend first, but not backend only

I am a senior PHP and Laravel developer based in Bulacan, Philippines. Most of my work has been the part users never see: the schema, the queue, the API contract, the admin panel someone in operations lives inside eight hours a day.

That work has mostly been for businesses with something at stake in the transaction — a remittance that has to arrive, a cargo box that has to be trackable, a job application that has to reach a real employer. Those systems are unforgiving about correctness, which is where the habits come from: SOLID boundaries, tests with Pest, refactoring under Rector and PHPStan rather than rewriting.

I design APIs with the people consuming them in the room. Working alongside Next.js and React Native developers taught me that a data contract settled early costs an afternoon, and one settled late costs a sprint. I write Nuxt/Vue and Livewire front ends myself when a project needs it.

Lately I lean on AI-assisted workflows — Claude Code in particular — for the mechanical parts of delivery. It moves faster; the review standard stays the same.

What I do

Four things I get hired for

  • Backend

    Systems and APIs

    Laravel applications and the REST APIs around them. Sanctum and Passport for auth, Filament where operations needs an admin panel, queues for the work that should not block a request.

  • Data

    Schema and performance

    Database design that survives the second year, and the query work that follows when a table gets large. Finding the slow thing, proving it is the slow thing, then fixing it.

  • Change

    Safe refactoring

    Legacy PHP brought forward without a rewrite. Pest for coverage, Rector and PHPStan for the mechanical lift, Pint to stop the diff arguments.

  • Delivery

    Working with front-end teams

    Contracts agreed before either side builds. I have shipped against Next.js, React Native and Nuxt teams, and I write the front end myself when that is the faster path.
